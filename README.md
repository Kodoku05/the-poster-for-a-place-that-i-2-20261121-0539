# Caelora

A deterministic Python program that draws a travel poster for the fictional floating isle of Caelora to `/output/entry.png`: golden dusk, a lighthouse, and a waterfall dissolving into a sea of clouds. All artwork is drawn programmatically with Pillow, with no network or downloaded assets.

## Run it

Requires Python 3.13, Pillow, and DejaVu fonts.

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

Without the environment variable, the output is `/output/entry.png`.
